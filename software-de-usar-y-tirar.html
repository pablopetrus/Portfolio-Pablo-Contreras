My prediction for 2027 and 2028: disposable software

I think that in four years, a significant share of the software we use will not even have a name.

We will create small applications to solve a specific problem and discard them once they have served their purpose.

Until now, because programming was expensive, it made sense to build tools that thousands of people could reuse. But if AI reduces that cost enough (to a marginal cost of practically zero), in many cases it will be easier to create a new tool than to learn how to use an existing one.

Perhaps we will end up treating much of our software the way we treat a document today: we create it, use it and forget about it. My Google Docs is full of fossils, and every day the code files on my computer look more like fossils too.
