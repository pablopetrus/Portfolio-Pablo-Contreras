Short Markdown files hold current context, decisions, and proven procedures. Review them when you return; update them when something changes.

Your first five minutes.

  1. Pick a task with a useful outcome.
  2. Ask the agent for a first result.
  3. Review what it produced against your sources.
  4. Record the decision and what comes next.

Only turn a task into a reusable procedure after you have tested that it works.

Suggested minimal structure

README.md — How to start.

AGENTS.md — Working instructions.

ESTADO.md — Current task, evidence and next step.

DECISIONES.md — Important decisions.

This is a proposed structure, not a verified package manifest. The public Starter release is still being prepared.

AGENT SECURITY REVIEW / MIT

A small open skill to review excessive permissions, exposed secrets, external integrations, dangerous tools and sensitive operations—and identify where human review is needed.

Get Agent Security Review on GitHub ↗

Start with a read-only review. Ask your agent to read the published SKILL.md, inspect its current permissions and report risks before making changes.

Optional local install

Copy skills/agent-security-review/ from the repository into .agents/skills/agent-security-review/ in your project, then ask your agent to use that skill.
