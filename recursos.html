WHY THIS EXISTS

Less organizing. More doing.

Not a second brain, a prompt collection, or a promise of automatic income. A lightweight way to keep useful work moving.

01

02

03

Reuse what has worked.

THE METHOD

How it works

1

Choose one task.

Define a concrete outcome that would actually move something forward.

2

Let the agent work and check the result.

Review the actual output, not just the agent's claim that it is done.

3

Record the decision and next step.

Store only what the next session needs to keep going.

GET STARTED

Your first five minutes.

This is the proposed minimum structure for the Starter. The downloadable package is not public yet; you can still try the method with a folder and your preferred coding agent.

my-work/
├─ README.md # How to start
├─ AGENTS.md # Agent rules
├─ ESTADO.md # Current task
└─ DECISIONES.md # Durable decisions
  1. Pick a meaningful task and define what done looks like.
  2. Ask your agent for a first useful result, with enough context to work.
  3. Check the outcome yourself; correct mistakes.
  4. Write the current state, decision, and next action in Markdown.

Short Markdown files hold current context, decisions, and proven procedures. Review them when you return; update them when something changes.
